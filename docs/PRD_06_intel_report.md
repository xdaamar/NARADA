# PRD-06: INTEL REPORT GENERATOR
## Laporan Intelijen Otomatis — Format Standar Militer

---

## 1. Ringkasan

Modul untuk menghasilkan laporan intelijen ancaman kognitif secara otomatis berdasarkan seluruh data analisis pada sesi tersebut, dalam format yang siap dicetak dan dilaporkan ke pimpinan.

---

## 2. Konfigurasi Laporan

User mengisi sebelum generate:
| Field | Tipe | Default | Wajib |
|-------|------|---------|-------|
| Nama Satuan | Text | "PUSSIBERAD TNI AD" | Ya |
| Nama Analis | Text | "" | Ya |
| Nomor Laporan | Text | Auto-generate "NRD-2026-XXX" | Ya |
| Klasifikasi | Select | "TERBATAS" | Ya |
| Sertakan Detail Temuan | Checkbox | true | Tidak |

---

## 3. Struktur Laporan

```
┌──────────────────────────────────────────┐
│  TENTARA NASIONAL INDONESIA — ANGKATAN DARAT
│  ══════════════════════════════════════════
│  NARADA                     No. NRD-2026-001
│  LAPORAN INTELIJEN          21 Oktober 2026
│  ANCAMAN KOGNITIF           Klasifikasi: TERBATAS
│──────────────────────────────────────────│
│                                            │
│  I. RINGKASAN EKSEKUTIF                   │
│     Jumlah analisis, ancaman terdeteksi,  │
│     breakdown per kategori dan level       │
│                                            │
│  II. STATISTIK ANALISIS                   │
│     Tabel: Kategori | Jumlah | % | Level  │
│                                            │
│  III. DETAIL TEMUAN ANCAMAN (opsional)    │
│     Per temuan: kategori, level, konten,   │
│     confidence, rekomendasi                │
│                                            │
│  IV. VERIFIKASI FAKTA                     │
│     Hasil cross-reference dengan database  │
│     fact-check (jika ada)                  │
│                                            │
│  V. REKOMENDASI TINDAKAN                  │
│     Berdasarkan severity tertinggi         │
│                                            │
│──────────────────────────────────────────│
│  Footer: Generated by NARADA v1.0         │
│  Halaman 1 dari 1 | Klasifikasi: TERBATAS│
└──────────────────────────────────────────┘
```

---

## 4. Export Options

| Format | Metode | Keterangan |
|--------|--------|------------|
| **Print** | `window.print()` | CSS print-optimized |
| **PDF** | Print to PDF (browser native) | Melalui dialog print |

---

## 5. Live Preview

- Report preview ditampilkan real-time di panel kanan
- Update otomatis saat konfigurasi berubah
- Background putih (print-friendly) dengan border merah militer

---

## 6. Acceptance Criteria

- [ ] Konfigurasi laporan (satuan, analis, nomor, klasifikasi) berfungsi
- [ ] Preview laporan update real-time
- [ ] Laporan mencakup: ringkasan eksekutif, statistik, detail temuan, rekomendasi
- [ ] Hasil fact-check (jika ada) disertakan dalam laporan
- [ ] Print/PDF export menghasilkan output bersih dan profesional
- [ ] Format visual konsisten dengan standar dokumen militer
